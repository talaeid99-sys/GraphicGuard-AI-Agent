GraphicGuard — Vercel

1. Upload the contents of this folder to a GitHub repository (not the ZIP itself).
2. In Vercel, Add New > Project > Import the GitHub repository.
3. Keep the default framework as Other; deploy.
4. Open the deployment URL and test the form and Python recommendation.
5. Convert the URL to a QR code for the presentation.

Note: This is a rule-based prototype, not a trained AI model.
